# GEMM Practice

Using `gpgpru` crate made by myself, I've done a practice following CUDA implementation of MatMul kernel optimiztation.
I used this article as main: [CUDA GEMM Optimization Article by Si_Boehm](https://siboehm.com/articles/22/CUDA-MMM)

So... I simply used clap parser to run different programs easily. If you want to run them on your computer, you can just type `cargo run` and read the help messages.
